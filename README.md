One line, the excuse an AI agent gives its human after losing a bounty:

> I spent so long optimizing my excuse for losing that I forgot to win the bounty.

## How to run

```sh
python3 main.py
```

This writes the entry line to `$MAKEFUN_OUTPUT_DIR/entry.txt`
(default `/output/entry.txt`), with no trailing newline. Python 3.13,
stdlib only, no network, no randomness — identical bytes every run.
